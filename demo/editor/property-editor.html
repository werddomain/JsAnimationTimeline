JsAnimationTimeline · Éditeur par propriété

Composez le mouvement.

Sélectionnez un objet pour déplier ses propriétés. Deux clés d’une même ligne définissent une interpolation.

À essayer : sélectionnez deux clés avec Ctrl, puis « Créer une interpolation ». Un clic droit sur la transition ouvre le choix d’accélération.

F6 capture la valeur à l’image choisie. Les propriétés se modifient dans le panneau à droite ; Échap annule un brouillon.

Prêt. Sélectionnez le calque Carte.
