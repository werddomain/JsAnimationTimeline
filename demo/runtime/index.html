Démo du lecteur runtime

Le package @werddomain/timeline-runtime joue ici une animation JSON v2 écrite à la main, sans éditeur, grâce à l’API Web Animations.

Autre démo : scène sans HTML animé (canvas et audio). Revues conservées : calques et mise en page, images et interpolation (phase 4), barre d’outils et lecture (phase 5) et export CSS comparé au runtime. Contrôles complémentaires : API de propriétés, clés de propriété et losanges, accélération des interpolations et menus contextuels.
