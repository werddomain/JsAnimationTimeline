Ce que l’export signale

Ces trois messages proviennent réellement d’un second document de contrôle, distinct de la scène comparée.

    Portée de la comparaison : ce document commence à l’image 1 et chaque sélecteur identifie un seul élément. Seules les cibles par sélecteur et les propriétés CSS connues sont exportables.

    Limites : le runtime anime le premier élément trouvé ; le CSS touche tous les éléments correspondants. Les courbes échantillonnées sont contrôlées aux images entières ; les temps intermédiaires ne sont pas garantis ici. Avant une première plage tardive, le CSS maintient son premier état dès 0 %, alors que le runtime peut garder le style initial. La boucle exportée est soit unique, soit infinie.
